L'écran FMC et le pilote automatique de votre simulateur, sur votre téléphone

Compatible avec le 737 MAX par défaut de Microsoft Flight Simulator 2024.

Télécharger SimCDU Bridge (PC) Application Android

Installation

  • Installez SimCDU Bridge sur votre PC Windows.
  • Installez le SDK MSFS 2024 (gratuit) : dans MSFS, Options > Général > Développeurs > Mode développeur, puis Help > SDK Installer.
  • Lancez MSFS et SimCDU Bridge, puis scannez le QR code avec l'application.
  • Dans MSFS, détachez l'écran du FMC (Alt droit + clic) : il apparaît sur votre téléphone.
